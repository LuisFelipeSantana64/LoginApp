# LoginApplication

LoginApplication is a simple web application that implements user registration and login functionalities.

## Backend

The backend is built with **Flask**, handling routes for user registration and login in a local environment. User passwords are securely stored using **bcrypt hashing**. All user data is saved in a **SQLite database**, which I created and structured separately before integrating with the application.

## Frontend

The frontend is developed with basic **HTML and CSS**, providing simple and intuitive forms for registration and login.

## Key Features

- **User Registration:** All user information is saved directly into the SQLite database.
- **User Login Authentication:** Secure password hashing ensures safe login.
- **Simple Frontend:** Clear and straightforward interface for easy use.

## Technologies Used

- Python
- Flask
- SQLite
- bcrypt
- HTML & CSS
